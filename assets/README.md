# Launcher artwork

`BatteryNG-icon-master.png` was generated for BatteryNG from the text in
`BatteryNG-icon-prompt.txt`. The PNG launcher icons under
`app/src/main/res/mipmap-*/` are scaled and masked derivatives of this master.

The project rights holder, g3orgs, has authorized publication of this artwork
under the Apache License, Version 2.0. See [LICENSE](../LICENSE). No artwork
from the Ampere reference app is included in the BatteryNG application.
