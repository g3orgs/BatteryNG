## Deutsch

BatteryNG 0.12.3 verbessert die Einrichtung der schwebenden Anzeige für per APK installierte Apps auf Android 13 und neuer. Die App führt zuerst zur App-Info und erklärt, wie „Eingeschränkte Einstellungen zulassen“ aktiviert wird. Danach öffnet sie die Android-Freigabe für „Über anderen Apps einblenden“ und startet die Anzeige nach der Freigabe automatisch. Dafür sind keine ADB-Befehle nötig.

Unter Einstellungen → Information zeigt BatteryNG jetzt die installierte Version. Dort kann eine manuelle Prüfung der neuesten GitHub-Version gestartet oder GitHub Releases im Browser geöffnet werden. Nur die manuelle Prüfung benötigt Internetzugriff; Messwerte und Verlauf bleiben auf dem Gerät.

## English

BatteryNG 0.12.3 improves floating display setup for sideloaded APKs on Android 13 and newer. The app first opens App info and explains how to allow restricted settings. It then opens Android's display-over-other-apps permission screen and starts the display after permission is granted. No ADB commands are needed.

Settings → Information now shows the installed version, offers a manual check of the latest GitHub release, and links to GitHub Releases in the browser. Only the manual check needs network access; readings and history stay on the device.
